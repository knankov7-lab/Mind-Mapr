# MindMapr Frontend (React + React Flow)

## Стартиране
```bash
npm install
npm start
```

## Функции
- Drag&Drop възли
- Свързване на възли (edges)
- Zoom/Pan + MiniMap
- Realtime екипна работа (WebSocket) – стаи (room)
- Room Guests панел (кой е онлайн в стаята)
- Управление на гости (owner/admin): viewer/editor/remove
- Контекстно меню за shape/color на възли
- Tutorial за нови потребители (първи login + ръчно отваряне)
- Чат, коментари и присъствие
- AdminPanel с role badges и Role Audit
