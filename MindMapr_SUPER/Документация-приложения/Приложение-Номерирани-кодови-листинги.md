# Приложение: Номерирани кодови листинги на MindMapr SUPER

Настоящото приложение съдържа същите основни модули на системата, но с номерирани редове за по-лесно рефериране по време на дипломна защита, обсъждане на архитектурата и анализ на конкретни реализации.

## Съдържание на номерираните листинги

- backend/admin.js - Backend модул за администрация
- backend/auth.js - Backend модул за автентикация
- backend/db.js - Backend модул за достъп до база данни
- backend/server.js - Backend сървър и API
- backend/time.js - Backend помощен модул за време
- frontend-react/src/EditorApp.js - Основен React редактор
- frontend-react/src/AdminPanel.js - Административен панел
- frontend-react/src/api.js - Клиентски API слой
- frontend-react/src/App.js - Коренов React компонент
- frontend-react/src/AuthContext.js - Контекст за автентикация
- frontend-react/src/MapHistoryDialog.js - Диалог за история на карти
- frontend-react/src/MapListDialog.js - Диалог за списък с карти
- frontend-react/src/OnlineMapsPage.js - Страница с онлайн карти
- frontend-react/src/PublicMapsPage.js - Страница с публични карти
- frontend-react/src/index.js - Входна точка на frontend приложението
- frontend-react/src/time.js - Frontend помощен модул за време
- frontend-react/src/styles/app.css - Основни стилове на приложението
